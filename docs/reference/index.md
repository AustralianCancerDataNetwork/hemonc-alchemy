# API reference

Use the narrative guides to choose a conceptual boundary, then use the reference pages for signatures, generated fields, and complete module surfaces.

- [Model entities](entities.md) — generated classes and their documented fields.
- [Toolkit API](toolkit.md) — core queries, treatment analytics, and scheduling helpers.
- [CLI](cli.md) — validation, auditing, diffing, and model regeneration.

The generated surface is broader than the common examples because it follows the current HemOnc data dictionary. Treat generated files as schema output rather than application extension points.
